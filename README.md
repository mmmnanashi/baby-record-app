# 育児ログ（家族共有版）

授乳・睡眠・おむつ・体温・メモを記録して、家族のスマホでリアルタイムに共有できる育児記録アプリです。
GitHub Pages で公開し、データは Firebase（Googleログイン + Firestore）に保存します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（デザイン） |
| `app.js` | アプリの動き（ログイン・記録・同期・分析） |
| `icons.js` | イラストのアイコン |
| `firebase-config.js` | **自分のFirebase設定に書き換えるファイル** |
| `firestore.rules` | データを守るセキュリティルール（Firebaseに貼り付ける） |
| `manifest.webmanifest` / `sw.js` / `icon-*.png` | ホーム画面に追加してアプリのように使うための設定 |

## 公開までの手順

### 1. Firebase プロジェクトを作る
1. https://console.firebase.google.com/ を開き「プロジェクトを作成」
2. プロジェクトのトップで「ウェブ」（`</>` アイコン）を選んでアプリを登録（Hostingのチェックは不要）
3. 表示される `firebaseConfig` の値を、`firebase-config.js` にコピーする

### 2. Googleログインを有効にする
「Authentication」→「始める」→「Sign-in method」→「Google」を有効にして保存

### 3. Firestore を作ってルールを設定する
1. 「Firestore Database」→「データベースの作成」
   - ロケーションは `asia-northeast1（東京）` がおすすめ
   - 「本番環境モード」で作成
2. 「ルール」タブを開き、中身を全部消して `firestore.rules` の内容を貼り付け →「公開」

> ルールを貼らないと、アプリは動きません（本番環境モードは全部拒否が初期値のため）。
> 逆に「テストモード」のままにすると誰でも読み書きできてしまうので、必ずこのルールに差し替えてください。

### 4. GitHub に上げて公開する
1. GitHubで新しいリポジトリを作る（例：`babylog`）
2. このフォルダのファイルをすべてアップロード
3. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存
4. 数分で `https://ユーザー名.github.io/babylog/` が開けるようになります

### 5. 公開したURLをFirebaseに登録する
Firebaseの「Authentication」→「設定」→「承認済みドメイン」→「ドメインを追加」で
`ユーザー名.github.io` を追加（これがないとログインできません）

### 6. 使いはじめる
1. スマホで公開URLを開き、Googleでログイン →「家族のノートを作る」
2. 「設定」→「家族を招待する」でコード（48時間有効）を作り、リンクを家族に送る
3. 家族はリンクを開いてGoogleでログイン →「参加する」
4. ホーム画面に追加しておくと、アプリのように全画面で開けます
   - iPhone：Safariの共有ボタン →「ホーム画面に追加」
   - Android：Chromeのメニュー →「ホーム画面に追加」（「アプリをインストール」）

以前の「この端末だけ版」で記録していたスマホでログインすると、残っている記録を家族のノートに取り込むか聞かれます。

## 仕組みとセキュリティ

- 記録は `families/{家族ID}/events` に保存され、**その家族のメンバーだけ**が読み書きできます（`firestore.rules`）。
- 家族に入れるのは、作った本人か、有効期限内の招待コードを持っている人だけです。
- `firebase-config.js` の値（apiKey など）は公開されても問題ない値です。データはルールで守られます。
- 電波がないときも記録でき、つながったときに自動で同期されます。
- 料金：家族で使う程度なら Firebase の無料プラン（Spark）の範囲で収まる想定です。

## アプリを更新したとき

`sw.js` の `VERSION`（`'v1'` → `'v2'` など）を上げてからアップロードしてください。
古い画面がキャッシュに残るのを防げます。

## メモ

- Firebase SDK は 12.19.0 に固定しています（`app.js` の先頭）。
- 分析タブは直近30日まで。それより前の記録もデータとしては残り、「バックアップを書き出す」で全件取り出せます。
- 家族から全員が抜けると、その家族の記録には誰もアクセスできなくなります。最後の1人が抜ける前にバックアップを書き出してください。
